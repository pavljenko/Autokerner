# Autokerner 9 Hybrid 0.1.0 beta

Поместите `Autokerner9.py` в Scripts FontLab 9 и обновите меню Scripts.
Для показанного сочетания выберите Spacing: Autokerner, Kerning: FL Neural.
Посчитайте/сравните, просмотрите и примените выбранные правки. Сохраните исходник.

Настройки отделены от Classic. Полный интерфейс, Fine-tuning и RU/EN/DE сохранены.
Авторская текстовая kern требует Add to it. На нескольких мастерах Apply
применяет апроши и готовит план экспорта, сохраняя kern исходника. Предпросмотр
не выполняет шейпинг текстовой kern. Для VF импортируйте включённый профиль
`resources/Autokerner9-compatible-TT.fl_profile`. Точная avar проверена на
одноосевом Nunito/v1. Откат не удаляет уже экспортированные файлы.

[Полная инструкция и ограничения](https://github.com/pavljenko/Autokerner/blob/main/docs/fontlab9.ru.md).
Бета проверена на macOS FontLab 9.0.9806; Windows не проверен.
Окончательный выбор остаётся за дизайнером.
