# Autokerner 9 Hybrid · 0.1.0 beta

[Скачать ZIP](https://github.com/pavljenko/Autokerner/releases/download/fl9-v0.1.0-beta.1/autokerner-fontlab9-v0.1.0-beta.1.zip)
· [Проверки](validation/README.md)

Полный интерфейс стабильной версии сохранён. Добавлены независимый выбор
движков апрошей и кернинга, сравнение предложений, сохраняющий путь для
авторской текстовой `kern`, экспорт TT-мастеров/VF и перенос исходной
поддерживаемой `avar` через обычное сохранение VFJ.

Для показанного на слайде сочетания выберите **Spacing: Autokerner**,
**Kerning: FL Neural**. Скрипт не выбирает «лучший» вариант автоматически:
после Calculate / Compare proposals дизайнер просматривает и применяет правки.
Новые движки FontLab 9 полезны, а гибрид даёт возможность сочетать подходы.

Установка: поместите `Autokerner9.py` в папку Scripts FontLab 9 и обновите
меню Scripts. Для VF-экспорта импортируйте включённый профиль
`resources/Autokerner9-compatible-TT.fl_profile`. Настройки версии для FontLab 8
не переписываются. Языки RU/EN/DE и Fine-tuning сохранены.

Авторская текстовая kern требует **Add to it**. В многомастерном случае Apply
применяет апроши и готовит план экспорта; исходная kern остаётся. Кнопки
Export VF / Export TT masters создают файлы. Revert отменяет апроши и план,
но не удаляет уже экспортированные файлы.

Предпросмотр Classic не воспроизводит эффективный шейпинг текстовой kern,
включая простые пары. Неподдерживаемый синтаксис блокируется. Точное сохранение
avar проверено на одноосевом Nunito, avar v1; универсальная поддержка осей
и профилей не заявляется. Проверено на macOS FontLab 9.0.9806; Windows не проверен.

[Слайды и методика](fontlab9.md#spacing-examples): три исходных входа без
порчи и один контролируемый. Yanone исключён из подборки. Локальные примеры
не доказывают общего превосходства. Скрипт не заменяет работу дизайнера.
