# Autokerner 1.0.1 for FontLab 8

Copy `Autokerner.py` to FontLab 8's Scripts folder, then choose
Scripts → Refresh Scripts. macOS: `~/Library/Application Support/FontLab/FontLab 8/Scripts`.
Windows: `%APPDATA%\FontLab\FontLab 8\Scripts` (Windows unverified).

Save a source copy. Calculate, inspect Preview/Edits, choose changes, then Apply.
Fine-tuning, selected glyphs/masters, RU/EN/DE, reports and Revert are retained.
1.0.1 repairs independently changed composite-letter spacing. Kerning defaults
are unchanged. Authored text `kern` is still removed when writing kerning in
this Classic edition; use the separate FL9 preserving route where needed.
