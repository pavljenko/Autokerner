# Автокернер 1.0.1 для FontLab 8

Поместите `Autokerner.py` в папку Scripts FontLab 8 и обновите меню Scripts.
macOS: `~/Library/Application Support/FontLab/FontLab 8/Scripts`.
Windows: `%APPDATA%\FontLab\FontLab 8\Scripts` (не проверен).

Сохраните исходник. Посчитайте, просмотрите правки, выберите нужные и примените.
Fine-tuning, языки RU/EN/DE, мастера и выделение, отчёты и откат сохранены.
Исправлены апроши составных букв. Настройки кернинга прежние. В этой Classic-версии
запись кернинга по-прежнему снимает текстовую feature kern, включая ручной код.

[Полная инструкция](https://github.com/pavljenko/Autokerner/blob/main/docs/fontlab8.ru.md).
Свежий прогон в FontLab 8 недоступен; исторические проверки — 8.4.3/macOS.
Проверяйте результат визуально. Универсального улучшения не обещаем.
