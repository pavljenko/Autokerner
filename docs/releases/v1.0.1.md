Classic bug-fix release for FontLab 8, with the matching browser build.

- Fixed independently changed sidebearings of composite letters such as i/j.
  They are measured from resolved outlines; source components remain components.
- Reference density, selected scope, protections, Fine-tuning and the full
  RU/EN/DE interface are retained. Kerning defaults are unchanged.
- Updated manuals, installation archives and SHA-256 checksums.

The defect was reproduced in the unmodified 1.0.0 calculation on five real
fonts; Karla is an outline-glyph control. 114 tests, one skipped, no failures.
The repair was tested with Apply/read-back/Undo in FontLab 9. Historical FL8
coverage is 8.4.3/macOS; a fresh FL8 runtime and Windows were unavailable.

Download `autokerner-v1.0.1.zip` for FontLab 8, or `autokerner-web-v1.0.1.zip`
for the browser files. The FontLab 9 hybrid is a separate beta release.
Review results; no universal optical improvement is promised.

RU: исправлены независимо изменённые апроши составных букв. Интерфейс и
настройки сохранены; универсального улучшения не обещаем.
