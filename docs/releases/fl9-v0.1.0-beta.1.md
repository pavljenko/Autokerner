First public beta of Autokerner 9 Hybrid, on the full Classic interface.

- Choose Autokerner or FontLab 9 engines independently for spacing and kerning.
- Compare proposals before selecting what to review and apply.
- Preserve authored text `kern` through an explicit Add route, with MM/VF export
  planning and supported original `avar` storage through normal VFJ Save.
- Includes the composite-letter spacing repair from Classic 1.0.1.

FontLab 9's improved engines make useful combinations possible. For example,
try Autokerner spacing with native kerning. This is not a universal replacement:
the designer still makes the final choice.

Download `autokerner-fontlab9-v0.1.0-beta.1.zip`; it includes the script,
export profile, instructions and licenses. Read the limitations before use:
Preview does not shape authored text kern; MM text kern is an export plan;
exact avar coverage is one-axis Nunito/v1; macOS tested, Windows unverified.

Six approved slides include the interface, study method and four selected
examples. Local examples are not an overall ranking of engines.
